# Problem

## User prompt

> blog posts doesnt have meta tags when I share I cant see images fix that

## Issue

Individual blog post pages do not expose complete social-sharing metadata. Link previews therefore omit the post image or render an incomplete card. The fix must derive page-specific Open Graph and Twitter metadata from each post, emit absolute public URLs, and preserve sensible site defaults where post data is absent.

## Clarifications

No user clarification required. The repository contains the page, content, and deployment configuration needed to determine the intended metadata contract.
